# Changelog

## 0.5
- Установка в два файла: APK игры и zip-архив с кэшем кладутся в одну папку `Android/data/com.jamescrumble.nova3/files/`,
  приложение само достаёт из архива оба файла `.obb`. Прежняя раскладка (`.obb` в `Android/obb/...`) по-прежнему подходит.

## 0.4
- Настройка «Лимит кадров» (30 / 60 / 90 / 120, по умолчанию 60): та же частота запрашивается у экрана, поэтому
  лёгкие сцены и меню больше не упираются в 60; при лимите ниже частоты экрана кадры придерживает мост.
- Настройка «Счётчик FPS» (можно выключить).
- Перенос сохранений со старого имени пакета: сборка `APP_ID=com.eaprules.nova3 tools/build_install.sh noinstall`
  обновляет старое приложение и на экране настроек выгружает сохранения в `Android/data/<старый пакет>/files/migrate`;
  эту папку нужно переложить в `Android/data/com.jamescrumble.nova3/files/`, новое приложение заберёт её при запуске игры.
- Цель ADPF берётся из лимита кадров, а не зашита как 60 fps.
- qemu, вариант F (по умолчанию): скалярные VFP add/sub/mul/div вставляются прямо в сгенерированный код,
  NEON f32 (арифметика, сравнения, min/max) считается целым регистром на NEON телефона, сравнения VCMP и
  флаги NZCV — в коде, сцепление блоков через границу страницы. На синтетике: VFP 200 -> 160 мс, NEON 48 -> 28 мс.

## 0.3
- **Новое имя пакета: `com.jamescrumble.nova3`** (было `com.eaprules.nova3`). Для Android это другое приложение:
  обновление поверх 0.2 невозможно. Установите 0.3, перенесите файлы игры в `Android/data/com.jamescrumble.nova3/files/`
  и `Android/obb/com.jamescrumble.nova3/`, затем удалите старое приложение.
- Звук: вывод напрямую из OpenSL ES порта в AudioTrack, темп задаёт динамик телефона — задержка больше не растёт
  со временем, пропали периодические щелчки. Пункт меню «Буфер звука».
- Мост GLES: вершины из общего (interleaved) массива передаются один раз, а не по копии на атрибут; для индексных
  отрисовок передаётся только используемый диапазон вершин. Меньше данных через пайп в сценах с толпой врагов.

## 0.2
- Меню настроек на старте приложения (угол обзора, разрешение 480–720p, кадры «в полёте», качество: тени,
  пост-эффекты, LOD, уровень деталей; закрепление на быстрых ядрах; физика в потоке; профилирование).
- Кадров «в полёте» 2 и командный пайп 1 МБ: заметно стабильнее FPS (swap wait почти пропал).
- Замена kuser cmpxchg (`0xffff0fc0`) на ldrex/strex в игровой библиотеке: ~13% времени главного потока.
- Свой FOV (`NOVA3_FOV_PERCENT`): расширение через `tan(fov/2)` прямо в пересчёте матрицы проекции;
  камеры HUD не трогаются.
- Профайлер гостя (`QEMU_GUEST_PROF`) и `tools/guest_prof.py`, `tools/prof_by_fps.py`.
- Оригинальная иконка, название «N.O.V.A. 3». Релизная подпись APK (`RELEASE=1 build_apk.sh`).
- Известно: редкое зависание экрана загрузки (см. PROJECT_STATE.md); выше 720p интерфейс игры ломается.
